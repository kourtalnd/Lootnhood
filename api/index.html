How an agent pays — no keys, no accounts

  1. Call any paid endpoint. You get an HTTP 402 with the price and payment requirements.
  2. Sign an EIP-3009 authorization in USDG on Robinhood Chain (x402 protocol, exact scheme).
  3. Retry with the X-PAYMENT header. Settlement happens on-chain and the data comes back in the same response.
